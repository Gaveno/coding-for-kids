# 🎮 Coding 4 Kids

A collection of visual, browser-based games designed to teach programming fundamentals to children who cannot yet read.

## ✨ Features

- 🚫 **No reading required** - All icons, emojis, and visual cues
- 📱 **Mobile-friendly** - Touch support for tablets and phones
- 🌐 **No dependencies** - Runs in any modern browser
- 📴 **Offline capable** - No internet connection needed
- ♿ **Accessible** - Large touch targets, high contrast colors

## 🎯 Games

### 🤖 Robot Path Painter
Guide a cute robot to paint patterns on a grid using movement commands.

**Skills taught:** Sequencing, loops, functions/procedures

**[Play Now →](robot-path-painter/index.html)**

### 🎵 Music Box Composer
Stack colorful blocks to create music patterns that a character dances to.

**Skills taught:** Sequencing, patterns, abstraction

**[Play Now →](music-box-composer/index.html)**

### 🎣 Robo Go Fish
Play Go Fish with a real 52-card deck against 1-3 friendly robots — collect sets of 4 matching parts to build the best robot! Three difficulty levels change how well the robots remember your asks.

**Skills taught:** Categorization & sets, counting, working memory, strategic thinking

**[Play Now →](robo-go-fish/index.html)**

### 🧮 Math Quest
Solve arithmetic problems along unlockable tracks — addition, subtraction, multiplication, and division. Finish a tap-the-answer track to unlock typing the answer digit by digit, then fill-in-the-blank equations like `4 + _ = 6`.

**Skills taught:** Addition, subtraction, multiplication, division, number sense

**[Play Now →](math-quest/index.html)**

### 🌻 Magic Garden *(Coming Soon)*
Create spell recipes to grow a magical garden.

### 🐱 Animal Dance Party *(Coming Soon)*
Teach animals dance moves by chaining actions together.

### 🏗️ Block Builder *(Coming Soon)*
Program a crane to build structures.

## 📚 Learning Progression

Each game introduces concepts progressively:

1. **Sequencing** - Put commands in order
2. **Execution** - Watch your code run
3. **Debugging** - Fix mistakes when things go wrong
4. **Loops** - Repeat actions multiple times
5. **Functions** - Save and reuse code blocks

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Gaveno/coding-for-kids.git
   ```

2. Open any game's `index.html` in a browser:
   ```bash
   cd coding-for-kids/robot-path-painter
   # Open index.html in your browser
   ```

No build step or installation required!

## 🧪 Running Tests

Open the test runner in your browser:
```
robot-path-painter/tests/index.html
```
